## 🌐 Como Publicar Online

### Opção 1: Vercel (Recomendado - Grátis)
```bash
# Instale Vercel CLI
npm i -g vercel

# Na pasta do projeto
vercel

# Segue as instruções na tela
```

### Opção 2: Netlify
1. Acesse: https://app.netlify.com
2. Faça login com GitHub
3. Clique "New site from Git"
4. Selecione seu repositório

### Opção 3: GitHub Pages (Grátis)
1. Crie repositório no GitHub
2. Envie os arquivos
3. Acesse Settings → Pages
4. Selecione branch e salve
